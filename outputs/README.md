# Start with the demo

Open [demo/START_HERE.md](demo/START_HERE.md), then [demo/Demo.html](demo/Demo.html).

The only source file you need to understand is [demo/pruning.py](demo/pruning.py). The runnable walkthrough is [demo/Demo.ipynb](demo/Demo.ipynb). Its assets load automatically.

Everything from the earlier experiments is preserved in [archive](archive/README.md). The archive is not needed to run the demo.
